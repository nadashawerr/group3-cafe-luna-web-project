# Café Luna – Local Café Website

Café Luna is a cozy, multi-page website created for ACIT 1620 – Fundamental Web Technologies. The site features a welcoming homepage with a hero section, a menu page showcasing drinks and pastries with descriptions, prices, and ratings, and an about page that highlights the café's story and atmosphere. The design focuses on clean layouts, readable typography, and a visually appealing, responsive interface that works across desktop and mobile devices.

The website is built using HTML5 and CSS3. Pages are structured semantically, and the menu page uses a responsive grid to display products elegantly. Images are used to enhance the aesthetic and support the cozy café theme. 

The project structure is organized as follows:

CafeLuna_Project/
├── index.html
├── menu.html
├── about.html
├── css/
│ └── style.css
└── images/

To view the site, open the HTML files in a web browser. CSS is linked externally in `style.css`, and all images are stored in the `images` folder. The project is designed for easy customization, deployment, and further development.
